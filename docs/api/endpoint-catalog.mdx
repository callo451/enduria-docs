# Endpoint catalog

All paths are relative to `/api/v1`. `admin:full` grants every operation. The deployment's [OpenAPI document](./reference) is authoritative for machine-readable schemas.

## Assets and clients

| Method | Path | Scope | Purpose |
| --- | --- | --- | --- |
| `GET` | `/assets` | `assets:read` | List assets |
| `POST` | `/assets` | `assets:write` | Create an asset |
| `GET` | `/assets/{id}` | `assets:read` | Retrieve an asset |
| `PATCH` | `/assets/{id}` | `assets:write` | Update an asset |
| `DELETE` | `/assets/{id}` | `assets:delete` | Delete an asset |
| `GET` | `/clients` | `clients:read` | List clients |
| `POST` | `/clients` | `clients:write` | Create a client |
| `GET` | `/clients/{id}` | `clients:read` | Retrieve a client |
| `PATCH` | `/clients/{id}` | `clients:write` | Update a client |
| `DELETE` | `/clients/{id}` | `clients:write` | Delete a client |
