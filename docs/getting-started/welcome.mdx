# Welcome to Enduria

Enduria brings service management, assets, projects, knowledge, licensing, and customer support into one multi-tenant platform. This documentation is for people who use, administer, integrate with, or self-host Enduria.

## Choose your path

- **Team members:** start with [First steps](./first-steps) and the [product guides](../product/overview).
- **Administrators:** configure access, branding, and connections in [Administration](../admin/overview).
- **Developers:** learn the public API contract in the [API overview](../api/overview).
- **Self-hosters:** begin with the [self-hosting overview](../self-hosting/overview).

:::note
Your organisation controls its own terminology, statuses, priorities, categories, and service targets. Screens may therefore differ slightly from examples in these guides.
:::

## Documentation conventions

Instructions name interface controls in **bold**. Examples use placeholders such as `https://your-enduria.example` and must be replaced with values from your deployment.
