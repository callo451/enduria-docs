# Using Enduria

Enduria provides one place to coordinate service work and the context around it.

| Area | Use it for |
| --- | --- |
| Tickets | Incidents, service requests, changes, problems, communication, time, and attachments |
| Assets | Hardware and software inventory, ownership, lifecycle, and related service history |
| Projects | Delivery planning, boards, timelines, risks, issues, dependencies, time, and expenses |
| Knowledge | Internal guidance and customer-facing answers with review and version history |
| Licensing | Products, contracts, entitlements, assignments, requests, and reclamation |
| Customer portal | Customer requests, updates, knowledge, and branded self-service |

Enduria is multi-tenant. Data access is always scoped to an organisation, and customer access can be scoped further. Your available actions depend on permissions rather than a universal job title.
